# viajes/

Viajes pasados, presentes y soñados de la familia.

## Subcarpetas

- `planificacion/` — viajes en curso o futuros (un `.md` por viaje).
- `recuerdos/YYYY/` — viajes hechos, con fotos referenciadas y notas.

## Archivos raíz

- `checklist-general.md` — qué meter siempre en la maleta (Bris incluido).

## Tools MCP

Fase 1: ninguno específico. Lectura/escritura con `vault_leer` / `vault_escribir`
genéricos. Tools dedicados llegarán en Fase 2-4.

## Principio

Los recuerdos son markdown legible. Si dejamos de usar Claudio, los viajes
siguen siendo nuestros.
