# lectura/

- `notas/` — notas largas por libro/artículo (un `.md` por fuente).
- `highlights/` — citas y subrayados (sincronización futura con Readwise/Kindle).

## Archivos raíz

- `cola.md` — qué leer, en orden o sin orden.
