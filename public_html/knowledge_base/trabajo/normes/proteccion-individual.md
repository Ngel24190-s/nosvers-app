# Protección individual obligatoria

## Stack base por operario

- Combinaison étanche jetable type 5/6, capuche, manchettes (cambio
  cada turno o al salir SAS).
- Masque P3 / TM3P facial complet selon empoussièrement.
- Filtres P3 (cambio según fabricante + duración expo).
- Bottes décontaminables / surchaussures.
- Gants nitrile sous gants travail.
- Casque si zone de chute.

## Procedimiento decontaminación SAS (3 compartiments)

1. Pre-douche habillé.
2. Despego combinaison externe (sac amianto).
3. Douche corps, filtros guardados.
4. Salida zona limpia.

## Stock mínimo recomendado por chantier (semaine type)

- 30 combinaisons × operario × semaine.
- 20 paires gants nitrile.
- 1 jeu filtres / 4h trabajo / operario.
