# familia/

Núcleo familiar de Angel + África + Bris.

## Subcarpetas

- `recordatorios/` — eventos fechados (cumpleaños, citas, gestiones). Cada
  recordatorio = un `.md` con frontmatter `{fecha, autor, prioridad, hecho}`.
  Los completados se mueven a `recordatorios/completados/`.
- `decisiones/` — decisiones familiares importantes (compras grandes, viajes,
  cambios de vida). Una entrada por decisión.
- `conversaciones/` — capturas opcionales de conversaciones relevantes.

## Archivos raíz

- `cumpleanos.md` — lista anual con un cumpleaños por línea.

## Tools MCP

- `recordatorio_crear`, `recordatorios_listar`, `recordatorio_completar`
- `familia_cumpleanos_listar`

## Privacidad

Contenido íntimo. No se indexa por `documentos_buscar`.
