# casa/

Casa de Neuvic-sur-l'Isle: electrodomésticos, mantenimiento, reformas.

## Subcarpetas

- `reformas/` — proyectos de reforma con su historial.

## Archivos raíz

- `electrodomesticos.yaml` — inventario con fecha de compra, garantía,
  manuales. Útil cuando algo se rompe.
- `mantenimiento.md` — bitácora de tareas hechas (deshollinado chimenea,
  revisión caldera, etc.).
