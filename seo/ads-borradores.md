## META ADS (Instagram + Facebook)

### Campaña 1 — Remarketing (la más rentable al inicio)
Reimpacta a quien visitó web o perfil.
- **Público:** visitantes web (Pixel, 30-180 días) + engagement IG/FB.
- **Creatividad:** producto + recordatorio ("Votre sol vous attend").
- **Presupuesto:** 3-5 €/día.

### Campaña 2 — Conversión catálogo
- Catálogo Meta sincronizado con WooCommerce (plugin oficial) + Pixel + CAPI.
- **Presupuesto:** 5-10 €/día.

### Campaña 3 — Awareness / historia (marca)
El ángulo diferencial: **la historia**, no la foto de producto sola.
- **Público:** intereses jardinage bio, permaculture, potager, autosuffisance · FR · France (o radio Dordogne para ateliers).
- **Presupuesto:** 5 €/día.

**Creatividades (copy listo):**

*Angle historia (el más fuerte):*
```

cette terre autrement. Aujourd'hui, Angel élève les vers, África transmet.
```

### Pre-requisitos Meta
- Business Manager + cuenta publicitaria + método de pago.
- Meta Pixel + Conversions API en la web.
- Catálogo conectado a WooCommerce.

---

## Secuencia de lanzamiento
1. Montar tracking (Google conversions + Meta Pixel/CAPI). **Innegociable.**
2. Arrancar Google PMax/Shopping + Meta Remarketing (lo más rentable).
3. Medir 2-3 semanas → cortar lo que no convierte, escalar lo que sí.
4. Añadir Search (Google) + Awareness historia (Meta) cuando haya datos.
5. Reinvertir margen en SEO (contenido + backlinks) → menos dependencia del pago.

## Nota honesta
Los Ads dan ventas desde el día 1 si producto/precio/tracking están bien, pero **no suben el ranking orgánico**. Su mayor valor secundario: los datos de qué keywords *venden* → priorizan el SEO real.
